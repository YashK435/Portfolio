System Overview

The Dynamic NPC AI System is designed as a system-first prototype where AI interaction replaces traditional scripted dialogue trees. All NPCs share a single AI framework, with behavioral diversity emerging purely from attribute configuration.

Current Implementation

Shared AI Architecture

All NPCs operate on the same AI logic layer. Personality, tone, and response behavior are controlled entirely through attribute values, allowing scalability without duplicated logic or content.

NPC World Behavior

NPCs exist as active world entities. They roam freely, pause movement on player proximity, and transition seamlessly into AI-driven dialogue without menu-based interaction.

Text-to-Text Interaction

Player input is free-form text. There are no dialogue options or prompts. The system is intentionally open-ended to evaluate response diversity, immersion consistency, and architectural clarity.

Core Interaction Loop

Player Approaches NPC → AI Interaction Triggered → Free-Form Text Input → Attribute-Conditioned AI Response → Dialogue Ends → NPC Resumes World Behavior

Current Limitations

  • No conversational memory or persistence
  • No world-state changes driven by dialogue
  • No progression, failure, or success conditions
  • Text-only interaction (no voice)

These limitations are intentional to keep the prototype focused on evaluating system scalability and behavior variation.

Future Scope

Voice-to-Voice Interaction

Replace text input/output with Speech-to-Text (STT) and Text-to-Speech (TTS), keeping the underlying AI logic unchanged.

Conversational Memory

Introduce short-term and long-term memory, allowing NPCs to remember past interactions, contradictions, and player intent.

Visual Feedback

Drive facial animation, tone modulation, and emotional feedback using meta human lipsync directly from AI response analysis.

Full Gameplay Integration

Expand the system into a deduction-based experience where players must infer truth through conversation alone.
