Overview

System Overview

The Dynamic NPC AI System is designed as a system showcase where AI-driven interaction functions as the core mechanic rather than a supporting feature. The goal is to demonstrate how a shared AI framework can generate distinct conversational behavior across multiple NPCs using attribute-based logic instead of traditional scripted dialogue trees.

All four NPCs operate on the same underlying AI logic. Behavioral variation is achieved exclusively through unique attribute assignments — allowing the system to scale without duplicating logic or content. One framework. Four distinct personalities. Zero scripted trees.

Set in a medieval-inspired environment, NPCs roam freely as active world entities rather than static interaction points. The system prioritizes architectural clarity, scalability, and a clearly defined roadmap for expansion.

Interaction

Core Interaction Loop

Player Approaches NPC → NPC Pauses Roaming → Dialogue Interface Triggered → Free-Form Text Input → Attribute-Conditioned AI Response → Dialogue Ends → NPC Resumes World Behavior

There are no predefined dialogue choices. The player may ask any question, enabling open-ended experimentation with the AI system. The interaction model prioritizes world believability over menu-driven patterns.

Architecture

How It Works

🧠

Shared AI Framework

All NPCs run on a single AI logic layer. There is no per-NPC code, no branching trees, no hand-authored responses. The framework generates all behavior from the underlying model.

⚙️

Attribute Configuration

Personality, tone, and response behavior are controlled entirely through per-NPC attribute values. The same player input produces different responses depending on which NPC you're speaking to.

🌍

World Behavior

NPCs roam autonomously within their world space. On player proximity, movement pauses and dialogue begins. When the conversation ends, NPCs resume their world behavior seamlessly.

Current Scope

Current Limitations

These limitations are intentional — keeping the prototype focused on evaluating attribute-driven behavior and system scalability without compounding complexity.

  • No conversational memory or persistence — each interaction is stateless
  • No world-state changes driven by dialogue outcomes
  • No progression gates, failure conditions, or success states
  • Text-only interaction — no voice input or output yet

The system functions as a sandbox AI interaction layer, not a complete gameplay loop. This is intentional for architectural evaluation.

Roadmap

Future Scope

Planned extensions that build on the current architecture without requiring fundamental rewrites.

🎙️

Voice-to-Voice Interaction

Speech-to-Text replaces player text input. Text-to-Speech replaces NPC text output. The core AI logic remains completely unchanged.

🧩

Conversational Memory

NPCs retain memory of previous questions, player tone, and logical contradictions. Memory influences future responses and trust levels within a session.

😶

MetaHuman Visual Feedback

Facial animation and lip-sync driven by dialogue output. Emotion-aware delivery through tone modulation analyzed from AI responses.

🔍

Deduction Gameplay

Full gameplay concept: an investigator interrogating four NPCs in a blacked-out space to identify a criminal through conversation alone. No traditional UI, no explicit markers — truth must be deduced.

📈

Dynamic Attribute Shifting

NPC attributes that evolve during gameplay based on conversation history, player behavior, and trust levels — creating NPCs that feel like they remember who you are.

🌐

World-State Integration

Dialogue outcomes that change NPC behavior, unlock areas, or alter the world. Conversation as a gameplay action with persistent consequences.

Current State

What's Working / What's Missing

What Is Working

  • Shared AI framework successfully generates diverse NPC behavior from attributes alone
  • Scalable architecture — adding new NPCs requires only attribute configuration
  • World-believable NPC behavior: roaming, pausing, conversing, resuming
  • Free-form text input enables genuine open-ended experimentation
  • Clear technical separation between AI logic and interface layers

What Is Still Missing

  • Conversational memory — every interaction resets to zero
  • No gameplay loop built around the system yet
  • Voice interaction layer not implemented
  • Visual feedback and facial animation not connected
