Game Overview

Loop.exe is a memory-based execution game where difficulty emerges from cognitive pressure rather than mechanical complexity. Players must input increasingly long command sequences while managing a limited number of execution threads. Every mistake permanently removes a thread, creating irreversible tension.

Core Gameplay Loop

Generate Sequence → Display on CRT UI → Player Inputs Keys → Correct Input Extends Loop → Incorrect Input Deletes Thread → All Threads Lost → Loop Purged

Key Systems & Design Decisions

Thread System

Threads represent the player’s remaining mental capacity rather than traditional health. They do not regenerate, enforcing permanent consequences and deliberate play.

Cognitive Difficulty Scaling

Difficulty increases naturally through longer input sequences and accumulated player pressure. No speed multipliers or artificial difficulty spikes are used.

CRT-Based UI Pipeline

The UI is rendered to a material and applied to a curved mesh to simulate a physical CRT display. This approach enhanced immersion but introduced minor input latency — a documented tradeoff.
